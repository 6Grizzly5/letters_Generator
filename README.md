# Letters Generator

App React (Vite) qui génère des lettres de demande de stage en PDF, 100 % dans le navigateur (aucun backend).

    npm install
    npm run dev      # test local
    npm run build    # build de production (dossier dist)

Tes informations personnelles se modifient dans `src/config.js`, les textes dans `src/lib/templates.js`.
Déploiement Vercel : framework Vite, build `npm run build`, sortie `dist`.
